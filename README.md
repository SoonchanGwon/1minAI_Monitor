# 1min.AI 크레딧 자동 모니터 (Windows Desktop App)

`https://app.1min.ai/`에 자동 로그인한 후, `https://app.1min.ai/billing-usage` 페이지로 이동하여 **Credit(크레딧) 잔여 현황**을 눈으로 확인하고 기록하는 Windows 데스크톱 애플리케이션입니다.

---

## 🌟 주요 기능

1. **브라우저 실제 화면 확인 (Visible Mode)**:
   * 백그라운드 숨김이 아니라 실제 Chrome 또는 Edge 브라우저 창이 뜨며 로그인 및 크레딧 페이지 이동 과정을 눈으로 직접 확인할 수 있습니다.
   * 확인 후 지정한 시간(기본 6초) 동안 브라우저 화면을 유지한 뒤 안전하게 종료합니다.

2. **CSV 기반 계정 관리 (`sites.csv`)**:
   * `URL,ID,PW,URL2` 형식의 CSV 파일을 읽어 자동으로 대상 사이트와 로그인 정보를 적용합니다.
   * 복수 계정이 기록된 경우 순차적으로 확인합니다.

3. **크레딧 잔여 현황 자동 추출 및 기록**:
   * Billing & Usage 페이지에서 Credit 잔여량 텍스트를 자동 파싱하여 앱 화면에 큼직하게 표시합니다.
   * 실행할 때마다 날짜/시간별 스크린샷(`screenshots/credit_...png`)을 자동 저장하여 증빙 및 기록을 남깁니다.
   * 조회 이력은 `history.csv` 파일에 누적 기록됩니다.

4. **매일 지정 시간 자동 실행 (스케줄러)**:
   * 앱 내에서 원하는 시간(예: `09:00`)을 지정하고 "매일 스케줄 시작"을 누르면 매일 정해진 시각에 자동으로 실행됩니다

## 💡 구글 로그인 & CAPTCHA(캡차) 완벽 해결 방법

구글(Google) 연동 로그인은 구글의 강력한 봇 탐지 정책으로 인해 자동화 툴이 아이디/비밀번호를 입력하려 할 때 캡차가 강제로 발생합니다.

이를 해결하기 위해 본 프로그램은 **"브라우저 프로필(세션 쿠키) 영구 저장"** 방식을 사용합니다:

1. **최초 1회만**:
   * 앱 실행 후 상단의 주황색 버튼 **`[최초 1회 구글 로그인 창 열기]`**를 클릭합니다.
   * 브라우저 창이 열리면 본인의 구글 계정으로 로그인하고 캡차를 한 번 풀어줍니다.
   * 로그인이 완료되면 브라우저 창을 닫습니다. (로그인 세션이 `browser_profile/` 폴더에 영구 저장됩니다.)
2. **이후 매일 실행 시**:
   * 저장된 세션이 유지되므로 **로그인 창이나 캡차를 전혀 거치지 않고 바로 `billing-usage` 페이지로 직행**합니다!
   * 매일 예약된 시간에도 사람 개입 없이 자동으로 크레딧을 읽어오게 됩니다.

## 🚀 사용 방법

### 1단계: 계정 정보 설정 (`sites.csv`)
`sites.csv` 파일을 엑셀이나 메모장으로 열고 본인의 1min.AI 로그인 계정과 비밀번호를 입력합니다.
```csv
URL,ID,PW,URL2
https://app.1min.ai/,your_account@email.com,your_password_here,https://app.1min.ai/billing-usage
```

> **주의 (로그인 방식 관련)**:
> 1min.AI 계정이 이메일/비밀번호 가입 계정이어야 자동 입력이 가능합니다. (Google SSO / Apple 계정으로 가입된 경우 해당 계정의 이메일 로그인 비밀번호가 설정되어 있는지 확인하세요.)

## 🖥 앱 화면 및 사용 팁

1. **지금 바로 크레딧 확인하기**:
   * 상단의 "지금 바로 크레딧 확인하기" 버튼을 클릭합니다.
   * 브라우저 창이 열리며 1min.ai로 이동하고, ID/PW가 입력된 뒤 `billing-usage` 페이지로 이동합니다.
   * 페이지의 크레딧 현황을 화면에 표시하고 스크린샷을 찍은 뒤 브라우저가 종료됩니다.
2. **매일 자동 실행**:
   * 시간 입력란에 `09:00`과 같이 실행할 시각을 넣고 **[매일 스케줄 시작]** 버튼을 누르면 프로그램이 켜져 있는 동안 매일 해당 시간에 자동으로 실행됩니다.
3. **스크린샷 및 히스토리 확인**:
   * "📸 스크린샷 보기"를 누르면 방금 캡처된 Billing 페이지 전체 이미지가 열립니다.
   * "📁 스크린샷 폴더 열기"를 누르면 날짜별 캡처 기록을 모두 볼 수 있습니다.
